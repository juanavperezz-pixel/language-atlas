# Language Atlas roadmap

## Completed — Version 1
- [x] Four language tracks
- [x] Mobile-responsive dashboard
- [x] Two example lessons per language
- [x] Retryable quizzes: wrong answers can be changed
- [x] Flashcards with simple spaced intervals
- [x] Knowledge reference shelf + searchable personal notes
- [x] Guided writing journal
- [x] Completion and study activity tracking
- [x] Local JSON backup/restore
- [x] GitHub Pages-ready static deployment

## Next — Version 1.1: learning science
- [ ] Placement assessment: avoid treating all four languages as beginner-level
- [ ] Daily goals and weekly study planner by language
- [ ] Full structured lesson curriculum (A0–B1), with source reviews
- [ ] Record quiz mistakes and offer targeted follow-up exercises
- [ ] Audio from vetted human voices, with attribution and licenses
- [ ] Better scheduling (e.g. FSRS), including same-session failed-card retries

## Later — Version 2: full personal academy
- [ ] Markdown/MDX knowledge articles with notes and backlinks
- [ ] File/photo attachments and source/reference metadata
- [ ] Pronunciation recording with user playback; optional feedback system
- [ ] Authentic dialogues, role-playing and cultural case studies
- [ ] Vocabulary import from CSV/Anki-style exports
- [ ] CEFR-inspired milestones, with clear limits on proficiency claims
- [ ] Authenticated cross-device progress sync and backup
- [ ] Optional AI tutor via secured server-side API keys; never client-side keys
- [ ] Offline-first installable PWA, after storage and sync are reliable
